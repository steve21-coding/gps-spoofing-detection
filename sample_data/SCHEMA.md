# Navigation CSV schema

One row per observation. Column names are case-insensitive. Files are limited to 10 MB / 250,000 rows.

| column | required | type | unit | notes |
|---|---|---|---|---|
| `timestamp` | **yes** | number or ISO-8601 string | seconds (or UTC date-time) | Unparseable rows are dropped; duplicates removed; rows sorted per trajectory |
| `lat` | **yes** | number | degrees, -90..90 | Out-of-range or non-numeric values are flagged as invalid observations |
| `lon` | **yes** | number | degrees, -180..180 | same |
| `alt` | no | number | metres | Needed by the `kinematic` and `full` feature sets |
| `speed_mps` | no | number | m/s | **Receiver-reported ground speed** (e.g. from Doppler), not derived from your coordinates. Needed by `kinematic` and `full` |
| `sat_count` | no | number | count | Satellites used in the fix. Needed by `full` |
| `cn0_dbhz` | no | number | dB-Hz | Mean carrier-to-noise density. Needed by `full` |
| `trajectory_id` | no | string | - | Separates flights/sessions in one file. Defaults to `traj_0` |

Columns `label`, `scenario` and `attack_onset_ts` appear only in labelled/synthetic data. They are used for
evaluation and are never used as model inputs.

## Feature sets

| set | needs |
|---|---|
| `position` | timestamp, lat, lon |
| `kinematic` | + alt, speed_mps |
| `full` | + sat_count, cn0_dbhz |

A model can only be run if your file provides the columns its feature set needs. Missing values inside a
column are allowed (they are imputed with training medians and flagged by `invalid_obs` when coordinates are missing).

## `example_navigation.csv`

Generated by `python -m ml.src.synthetic_data` helper `write_sample_csv()`: one **simulated** 200-second flight per scenario
(normal, glitch, dropout, low_sat_noise, jump, drift, consistent_drift, freeze). All data are synthetic.
